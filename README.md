# Taller PL/pgSQL — Sistema básico de inventario

Scripts del taller de Programación Extendida I (Bases de Datos 2).
Caso: TechStore — control básico de inventario en PostgreSQL.

## Scripts

| Archivo | Contenido |
|---|---|
| `scripts/01_modelo_datos.sql` | Tabla productos con restricciones y datos de prueba |
| `scripts/02_fn_consultar_stock.sql` | Función que consulta el stock de un producto |
| `scripts/03_fn_validar_disponibilidad.sql` | Función que valida existencia y stock suficiente |
| `scripts/04_sp_descontar_inventario.sql` | Procedimiento que descuenta inventario |
| `scripts/05_pruebas.sql` | Los tres casos de prueba obligatorios |

Motor: PostgreSQL 15+ (Neon)
